Limites explícitos

Isto ainda não é o sistema em operação.

Os botões demonstram navegação local. Upload, orçamento, pagamento, produção e entrega não estão conectados nesta página.

Roteiro sintético

Prévia local das etapas previstas para este perfil. Nenhuma ação é executada.

Como navegar pelo teclado

Nas abas de perfil e nas etapas, use as setas para navegar; use Início ou Fim para ir ao primeiro ou ao último item. Pressione Enter ou Espaço para selecionar. Dentro do roteiro, Alt+1 abre Cliente, Alt+2 abre Parceiro, Alt+3 abre Administrador, Alt+N avança, Alt+V volta, Alt+R leva ao resumo das jornadas, Alt+A pausa ou retoma os avisos de progresso e Alt+H abre ou fecha esta ajuda. Escape fecha o roteiro; durante uma confirmação de reinício, Escape cancela primeiro essa confirmação.
